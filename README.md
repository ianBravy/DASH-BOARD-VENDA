# Dashboard de Vendas - BRVY®

Dashboard interativo para análise de leads e conversões da BRVY®.

## 🚀 Deploy na Vercel

### Opção 1: Deploy via CLI da Vercel

1. **Instale a CLI da Vercel:**
   ```bash
   npm i -g vercel
   ```

2. **Faça login na Vercel:**
   ```bash
   vercel login
   ```

3. **Deploy do projeto:**
   ```bash
   vercel --prod
   ```

### Opção 2: Deploy via Interface Web

1. Acesse [vercel.com](https://vercel.com)
2. Faça login com sua conta
3. Clique em "New Project"
4. Conecte seu repositório GitHub ou faça upload dos arquivos
5. Configure as seguintes opções:
   - **Framework Preset:** Other
   - **Root Directory:** ./
   - **Build Command:** (deixe vazio)
   - **Output Directory:** ./
6. Clique em "Deploy"
